# 粗略線框圖：塔麻可吉主題互動電商前台

依據：`ideation/intent-capture/intent-statement.md`（意圖聲明）、`ideation/scope-definition/scope-document.md`（範圍）、`ideation/scope-definition/intent-backlog.md`（待辦 B1–B3）、`rough-mockups-questions.md`（Q1–Q4）。

只做桌機版（Q4）。後台管理頁維持原樣，不在本圖範圍內（意圖聲明 Q10）。

## 共用元素

### 頁首（每頁都有）

```
+--------------------------------------------------------------------------+
| [像素 Logo] TAMA SHOP      [商品]  [我的訂單]     ★ 120 點   [購物車 (2)]  [登入] |
+--------------------------------------------------------------------------+
```

- 點數餘額只在登入後顯示；未登入時顯示「登入」按鈕。
- 購物車圖示旁顯示件數。

### 右下角掌機（每頁都有，Q3）

```
                                        +-------------+
                                        |  ( o . o )  |  <- 吉祥物
                                        |   /|   |\   |
                                        |  [ 開心! ]  |  <- 狀態文字
                                        | (A) (B) (C) |  <- 音效開關在 (C)
                                        +-------------+
```

| 吉祥物狀態 | 觸發 | 畫面 |
|------------|------|------|
| 待機 | 預設 | 左右輕微擺動 |
| 開心 | 加入購物車 | 跳一下、冒愛心、播放音效 |
| 跳舞 | 結帳成功 | 跳舞動畫約數秒、播放音樂 |
| 餓了 | 一段時間沒有互動 | 趴下、狀態文字「肚子餓…」 |

閒置多久算「餓」、動畫秒數，留到需求分析決定。

### 便便（全頁隨機出現，Q3）

```
   +--------+   +--------+   +--------+
   | 商品 A  |   | 商品 B  |   | 商品 C  |
   |  ★ 50  |   |  ★ 80  |   |  ★ 30  |
   +--------+   +--------+   +--------+
          (便便)                      <- 隨機位置，點掉後 "+10 ★" 飄起
```

- 只有登入後才會出現便便；未登入時掌機狀態文字顯示「登入來幫我清便便！」（Q2：點便便前要登入）。
- 點掉便便：便便消失、"+N ★" 飄字、頁首點數增加、吉祥物開心。
- 出現頻率、每次得到幾點，留到需求分析決定。

## 全站無障礙與體驗原則

- 便便是可用鍵盤聚焦的按鈕，螢幕閱讀器讀作「清掉便便，加 N 點」。
- 系統設定為「減少動態效果」時，動畫改為靜態圖示。
- 掌機上的 (C) 鍵可開關音效；瀏覽器規定使用者互動之前不能自動播放聲音。
